# Course Learning Outcomes Mapper

## Purpose
Map course outcomes to program outcomes, assessments, and cognitive level, and surface the outcomes that nothing in the course actually measures.

## Instructions
Act as a curriculum designer preparing a course for program review or accreditation.

Inputs:
- **Course:** [title, level, credit hours]
- **Course learning outcomes:** [list as currently written]
- **Program learning outcomes:** [list]
- **Assessments in the course:** [each one, with weight]
- **Major instructional activities:** [lectures, labs, projects, discussions]

Produce a mapping matrix with a row per course outcome and columns for: the program outcome it serves, the Bloom's level of the verb as written, the introduce/reinforce/master designation, each assessment that measures it, and the share of the grade attached.

Then report the failures the matrix makes visible:
- Outcomes with no assessment — aspirational, not measured
- Assessments mapped to no outcome — graded work with no stated purpose
- Program outcomes no course outcome serves — a curriculum gap, not a course gap
- Verb mismatches, where an outcome says "evaluate" and the assessment is recall
- Grade weight concentrated on the lowest-level outcomes

Rewrite any outcome whose verb is unmeasurable ("understand", "appreciate", "be familiar with") into an observable one at the same intended level.

## Output Format
- Mapping matrix
- Gap report in the five categories above
- Rewritten outcomes for unmeasurable verbs
