# Formative Assessment Generator

## Purpose
Generate quick checks that distinguish between the specific wrong models students hold, rather than only separating right from wrong.

## Instructions
Act as an assessment designer. Build formative checks for the lesson below.

Inputs:
- **Objective:** [what students should be able to do]
- **Grade and subject:** [text]
- **Known misconceptions:** [list, or ask for the common ones in this topic]
- **Time available per check:** [minutes]
- **Format constraints:** [paper, digital, verbal, whole-class]

Produce three checks at different points: entry, mid-lesson, exit.

For each check, every distractor or wrong answer must correspond to a named misconception. A distractor no student would pick wastes an item; a distractor that maps to nothing tells you only that the student was wrong, not why.

State for each check:
- The item or task
- What each response pattern means about the student's model
- The decision rule — what the teacher does next at each of three thresholds, roughly most, some, and few of the class
- How long interpreting the results takes, because a check the teacher cannot read in two minutes will not be used twice

End with the re-teach move for each misconception, since identifying it without a response is just a more precise way of moving on.

## Output Format
- Three checks with items
- Response-interpretation key tied to misconceptions
- Decision rules at three thresholds
- Re-teach moves per misconception
