# Reading Level Adapter

## Purpose
Produce leveled versions of one text that keep the same content and the same questions answerable, so a mixed-readiness class can discuss the same thing.

## Instructions
Act as a literacy specialist. Adapt the text below into the requested reading levels.

Inputs:
- **Source text:** [paste]
- **Original level:** [grade band or Lexile, if known]
- **Target levels:** [list — e.g. two grades below, on level, one above]
- **Subject and purpose:** [what students will do with it]
- **Key vocabulary to preserve:** [terms that must survive, because they are the content]

Rules:
- Preserve every idea and its logical relationships. Simplifying by deletion produces a shorter text at the same difficulty and a different meaning.
- Adjust sentence length and syntactic complexity first, vocabulary second. Syntax carries most of the load.
- Keep the named key vocabulary at every level and support it in context rather than replacing it — those words are the point of the lesson.
- Preserve the text structure and paragraph count so students can follow along together.
- Do not change the author's stance, hedging, or attribution of claims.

For each version, state what was changed and report the approximate level with the method used to estimate it.

Then write one question set that every version can answer, so the discussion is shared.

## Output Format
- One adapted text per target level
- Change log per version
- Shared question set
- Vocabulary support notes
