# Classroom Behavior Support Plan

## Purpose
Build a behavior support plan from a function hypothesis rather than a consequence menu, because a plan that ignores what the behavior achieves will be outcompeted by the behavior.

## Instructions
Act as a behavior support specialist. Build a tiered plan for the situation below.

Inputs:
- **Behavior, described observably:** [what is seen and heard, not a label]
- **Frequency, duration, intensity:** [with how it was measured]
- **Antecedents:** [what reliably precedes it — setting, task, time of day, people]
- **Consequences:** [what happens immediately after, including adult response]
- **What has been tried:** [and what each produced]
- **Student strengths and interests:** [text]

Work in order:
1. Restate the behavior in observable terms if the input was a label.
2. Propose a function hypothesis — escape, attention, access, or sensory — and say which evidence supports it and what would disconfirm it.
3. Antecedent strategies that make the behavior unnecessary.
4. A replacement behavior that achieves the same function more efficiently than the problem behavior does. If it is slower or harder, it will not be used.
5. Response strategies, including what adults stop doing.
6. Data collection: what, who, how often, and the decision rule for changing the plan.

Flag anything in the input that suggests an unmet academic need, since behavior that appears only during one subject is usually a skill problem wearing a behavior costume.

## Output Format
- Observable behavior definition
- Function hypothesis with supporting and disconfirming evidence
- Tiered strategies: antecedent, teaching, response
- Data plan with a decision rule and review date
