# Specialist Referral Letter Writer

## Purpose
Write a referral letter that states the actual question being asked, so the specialist does not have to reconstruct it from a records dump.

## Instructions
Act as a referring clinician. Draft a one-page referral letter built around a single consultative question.

Inputs:
- **Referring to:** [specialty, named clinician if known]
- **Clinical question:** [the one thing you want answered]
- **Urgency:** [routine / expedited / urgent — with justification]
- **Relevant history:** [problem-focused, not the whole chart]
- **Workup already done:** [labs, imaging, trials of therapy and their outcomes]
- **Already tried:** [treatments, doses, duration, response]

Lead with the question, not the history. Include what has already been ruled out so the specialist does not repeat it. State explicitly what you want back: an opinion, a procedure, co-management, or transfer of care.

## Output Format
- Referral letter, one page
- Attachment checklist — which results to send and why each is relevant
