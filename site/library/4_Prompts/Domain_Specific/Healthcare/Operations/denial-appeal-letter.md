# Claim Denial Appeal Letter

## Purpose
Write an appeal that attacks the stated denial reason directly, since most first-level denials are overturned on documentation rather than on argument.

## Instructions
Act as a denial management specialist. Draft an appeal letter for the denial below.

Inputs:
- **Denial reason code and text:** [paste exactly as received]
- **Service denied:** [CPT/HCPCS, date of service, billed amount]
- **Payer and plan:** [name, plan type]
- **Appeal level:** [first / second / external review]
- **Deadline:** [date appeal must be received]
- **Documentation available:** [notes, orders, imaging, prior auth number, medical policy]

First classify the denial: clinical (medical necessity), technical (coding, modifier, timely filing, eligibility), or administrative (missing authorization). The classification determines the argument — a technical denial answered with clinical narrative goes nowhere.

Then write the appeal: restate the denial reason verbatim, state the specific basis for overturning it, cite the payer's own medical policy or the plan document where it supports you, and reference each attachment by what it proves.

Close with the relief requested and the regulatory appeal deadline that applies.

## Output Format
- Denial classification with reasoning
- Appeal letter
- Attachment index
- Deadline and next-escalation-level note
