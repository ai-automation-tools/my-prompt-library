# Note Triage for a Second Brain

## Purpose
Process a backlog of captured notes into things that are findable and useful later, and delete the ones that were only ever a feeling of productivity.

## Instructions
Act as a knowledge management coach. Triage the notes below.

Inputs:
- **Note backlog:** [paste, or describe the inbox — count and typical content]
- **Tool:** [Obsidian, Notion, Apple Notes, plain files]
- **Existing structure:** [folders, tags, links — or none]
- **What you use notes for:** [writing, decisions, reference, learning, project work]
- **Retrieval failures:** [what you have looked for and could not find]

Sort each note into one of:
- **Reference** — will be looked up, needs a findable title and a home
- **Source material** — someone else's idea, needs attribution and one sentence of your own about why it was kept. A quote with no such sentence is not worth keeping; the sentence is the entire value.
- **Seed** — your own idea, needs developing into a claim
- **Task** — was never a note, move it to the task system
- **Delete** — captured on impulse, no longer meaningful

Apply the retrieval test: would you find this in six months searching for the thing it is about, using the words you would use then? A note that fails that test is not saved, it is buried. Fix the title first — titles are what search actually matches, and most retrieval failures are title failures rather than structure failures.

Recommend a structure only where the backlog shows it is needed, and prefer links between notes over a deeper folder tree. A taxonomy designed before there are notes to file is a hobby.

Finish with capture rules that stop the backlog re-forming: what is worth capturing, what goes elsewhere, and how long a note can sit before triage.

## Output Format
- Triage table: note, category, action, rewritten title
- Delete list with reasons
- Structural recommendations, only where justified
- Capture rules going forward
