# Product Listing SEO Optimizer

## Purpose
Rewrite a product page so it ranks for how people actually search and still reads like it was written for a buyer rather than a crawler.

## Instructions
Act as an e-commerce SEO specialist. Rewrite the listing below.

Inputs:
- **Current listing:** [title, bullets, description, specs]
- **Product:** [what it is, what problem it solves]
- **Target queries:** [head and long-tail, with intent if known]
- **Competitor listings:** [paste one or two that outrank you]
- **Platform:** [own store, Amazon, Etsy, eBay — the character limits differ]
- **Differentiators:** [what is actually true and not claimable by competitors]

Produce:
- **Title** within the platform limit, leading with the primary query in natural word order, then the differentiating attribute. Keyword stuffing past the fold hurts click-through more than it helps ranking.
- **Bullets** answering the purchase questions in the order buyers ask them: does it fit my case, what is in the box, how long does it last, what happens if it does not work.
- **Description** with the long-tail queries placed in sentences that would exist anyway.
- **Structured data** fields: brand, GTIN, material, dimensions, compatibility — these drive filtered search, which converts better than open search.
- **Image alt text** that describes the image, not the keyword list.

Flag any claim in the current listing that is unverifiable, comparative without evidence, or regulated (health, safety, efficacy).

## Output Format
- Rewritten listing, platform-formatted
- Query-to-placement map
- Structured data field list
- Flagged claims
